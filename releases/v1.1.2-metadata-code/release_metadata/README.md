# VHD blind evaluation release v1.1.2

This is the first release built from the final 801 human-adjudicated questions.
Only `public/` and target-model runtime instructions may be supplied to an evaluator. Files under `private/`, previous responses, reviewer files, results, and the manuscript are prohibited.

Primary evaluation: 801 questions (Accuracy 333, PDI 178, HCE 290).
Registered PDI controls: 712 questions (four frame-order controls for each PDI item).
All primary inputs are silent and use the locked 16-frame schedule. Main and control outputs must be sealed and hashed before private scoring.
